# Changelog

## 0.1.0 (beta)

The first public release.

- Copy all videos, shorts and streams of a YouTube channel to the Internet Archive, one video at a time.
- Pause and resume at any time. A SQLite queue survives crashes and power cuts.
- Check a channel again to add only its new videos.
- Delete local files right after each upload. Keep a record of each video in the database.
- Show the download speed, the upload speed and the time left for the current video.
- Local web page ("The Archive Record") and a full command line.
- ffmpeg and Deno come with the package, so nothing else needs to be installed.
